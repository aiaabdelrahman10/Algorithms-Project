# Algorithms Project

This project contains implementations of two algorithmic problems using both recursive and non-recursive approaches.

## Problems

### 1. Balanced String

Implementation of the Balanced String problem using:

* Recursive approach
* Non-recursive approach

### 2. Dominator

Implementation of the Dominator problem using:

* Recursive approach
* Non-recursive approach
